RAMZUNA COMPLETE WEBSITE PACKAGE

This archive contains the entire available Astro website source and static assets from the updated project, including Lessons 1-5 and the Lesson 5 extension.

Main editable project files:
- src/          Astro pages, layouts, components, content and CSS
- public/       Images, audio, and other static files
- scripts/      Helper scripts
- package.json, package-lock.json, astro.config.mjs, tailwind.config.js, tsconfig.json

Also included:
- dist/         The provided static website output, including updated Lesson 5 HTML and images
- README.md, CURRICULUM-UPDATE.md and other project notes

To edit: install Node.js 22.12+; run npm ci then npm run dev. To rebuild: npm run build.
Note: The full Astro rebuild could not be verified in this environment due to unavailable dependencies; the two Lesson 5 static pages were generated and checked separately.
Externally embedded video requires a network connection. Some audio from the original external lessons was unavailable in the provided captures.
